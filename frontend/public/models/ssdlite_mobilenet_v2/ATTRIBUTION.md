The model files in this directory are the pretrained SSD Lite MobileNet V2
COCO object detection model hosted by the TensorFlow.js project:

https://storage.googleapis.com/tfjs-models/savedmodel/ssdlite_mobilenet_v2/model.json

They are used only as a browser-side baseline for recorded-video person
detection. DARSON did not train or validate this model on a security site.
The TensorFlow.js COCO-SSD implementation is published by Google under the
Apache License 2.0: https://github.com/tensorflow/tfjs-models/tree/master/coco-ssd
